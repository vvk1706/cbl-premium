The Generate application documentation workflow compiled program-level Markdown files from /docs into a fully structured, browsable HTML knowledge base covering the DLIS CICS/COBOL application suite.

Open docs/index.html

What this workflow does

📐

Determines structure

Analyses available Markdown files and organises content into functional sections and pages.

📝

Generates rich pages

Produces detailed HTML pages per topic — architecture diagrams, business rules, code excerpts, examples.

🔗

Cross-references pages

Builds a sidebar and inline links so readers can navigate the knowledge base without searching.

How the workflow ran

  • 1
    Prepare – Locate source documentation Scanned /docs/program/cobol/, /docs/business-rule/cobol/ and /docs/explain/ for DLIS Markdown files.
  • 2
    Generate knowledge base structure Produced a 14-page / 4-section site plan covering system overview, application intake, verification & payment, approval & issuance, and architecture.
  • 3
    Generate content pages (13 pages) Each page was authored independently with prose, Mermaid diagrams, tables, code snippets, examples, and business rules.
  • 4
    Assemble HTML site All pages written to docs/html/pages/; CSS and sidebar written to docs/html/assets/; root index at docs/index.html.
